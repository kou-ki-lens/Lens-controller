Lens controller 1.6.4 PC 配套程序

安装
1. 运行 LensController-1.6.4-Setup.exe，可自选安装目录。
2. 可选择创建桌面快捷方式和 Windows 登录自启动。
3. 从桌面或开始菜单打开控制面板。关闭窗口后会留在系统托盘。
4. 后台服务不会显示 CMD 窗口。

连接
1. 确认控制面板显示“服务运行中”。
2. 掌机与电脑首次蓝牙连接时，需要在 Windows 蓝牙设置中完成配对。
3. 在掌机选择 Xbox、DualShock 或自定义布局，再点击“开始桥接”。
4. USB 有线模式需要允许掌机 USB 调试。

触控板与屏保
1. 连接后会自动播放低亮度图片屏保。
2. 屏保期间整块屏幕均可作为双指触控板使用。
3. 默认轻触 3 次退出；应用内可设置为 3–20 次。
4. 幻灯片可设置 2–60 秒间隔，以及全循环或随机循环。
5. 触控板在 DualShock 4 和自定义 PlayStation 布局下有效。

如果启动服务时提示缺少组件：
1. 暂时关闭安全软件对安装目录的拦截。
2. 重新运行安装程序。
3. 详细错误见 %LOCALAPPDATA%\LensController\service-launch-error.log。

电量与震动
1. 电量为掌机 Android 系统的实时电池百分比。
2. Windows 游戏触发虚拟手柄震动时，震动会回传到掌机。
3. 可在应用“摇杆调校”区域关闭掌机震动反馈。

卸载
在 Windows“设置 → 应用 → 已安装的应用”中卸载 Lens controller。
卸载会清除程序目录、快捷方式、自启动项、日志、连接配置和本产品创建的防火墙规则。
